# PUIG VALUE WEB V1.4 — Responsive

Cette version adapte l'interface aux téléphones, tablettes et PC.

Améliorations :
- formulaire en 1 colonne sur smartphone ;
- 2 colonnes sur tablette ;
- disposition complète sur ordinateur ;
- résultats empilés et lisibles ;
- boutons adaptés au tactile ;
- champs plus grands sur mobile ;
- tableaux avec défilement horizontal fluide ;
- carte redimensionnée selon l'écran ;
- graphiques empilés sur mobile ;
- meilleure gestion des petits écrans ;
- suppression du zoom automatique sur certains mobiles ;
- autocomplete d'adresse plus facile à utiliser au doigt.

Fichier à remplacer sur GitHub :
- app/static/index.html

Le backend app/main.py ne change pas pour cette V1.4.
