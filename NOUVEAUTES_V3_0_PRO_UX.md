# PUIG VALUE V3.0 — Modules PRO dynamiques

- Autocomplétion d'adresse IGN dans Local commercial, Immeuble de rapport et Terrain, identique au parcours habitation.
- Sauvegarde des estimations PRO dans l'historique existant et réouverture des dossiers.
- Bouton « Nouvelle estimation » dans chaque module PRO.
- Sélecteur de méthode dynamique :
  - Local commercial : Comparaison / Capitalisation / Recoupement.
  - Immeuble de rapport : Comparaison / Capitalisation / Recoupement.
  - Terrain : Comparaison / Bilan résiduel / Recoupement.
- Le formulaire n'affiche que les champs utiles à la méthode sélectionnée.
- Le backend reçoit explicitement la méthode choisie et ne calcule que les approches demandées.
- En mode Recoupement, les méthodes disponibles sont confrontées sans moyenne mécanique à poids égal.
